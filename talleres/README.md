# Organizacion de talleres

Cada subcarpeta representa un taller independiente y utiliza nombres con dos digitos:

```text
taller_01/
taller_02/
taller_03/
```

## Estructura minima de un taller

```text
taller_XX/
|-- README.md              # Enunciado operativo, reparto y fechas
|-- TallerX_Grupo_NUMERO.R # Script unico de entrega
|-- borradores/            # Trabajo separado por responsable
|-- evidencias_IA/         # Conversaciones que deban declararse
`-- scripts/               # Validaciones auxiliares, no entregables
```

Al agregar un taller, tambien debe incluirse en la tabla principal del repositorio.
